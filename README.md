# 야구 기록장

경기별 타석·투구·수비, 훈련과 칼럼을 기록하는 한국어 개인 야구 아카이브입니다.

## 구성

- `index.html`: 화면과 기록·집계 로직. 기존 브라우저 저장 및 GitHub 동기화 방식을 사용합니다.
- `design-refresh.css`: 반응형 화면, 핵심 요약, 상세 접기/펼치기의 시각 스타일.
- `data.json`: 공개 화면이 읽는 기록. 코드 테스트에서 수정하지 않습니다.
- `draft-2023-2026.html`: 기존 독립 드래프트 분석 페이지.
- `CNAME`, `robots.txt`: 기존 도메인과 검색로봇 설정.

GitHub Pages에서 정적 파일을 제공하며 별도 빌드나 패키지 설치가 필요하지 않습니다.

## 회귀 테스트

Node.js 20 이상에서 실행합니다. 합성 데이터만 사용하며 GitHub에 요청하거나 실제 기록을 수정하지 않습니다.

```sh
node --test tests/*.test.cjs
```

테스트는 빈 타석 처리, 야구 지표 계산, 같은 날 투구수 합산, 훈련 수정/취소, 백업 병합, 콘텐츠 URL 처리 등을 확인합니다. 보안 테스트는 `qa-preview/security-fixture.html`도 생성합니다. 이 파일을 로컬 미리보기에서 열면 실제 브라우저 DOM의 HTML 정리 동작을 추가 확인할 수 있습니다.

## 유지보수 시 주의

- `data.json`은 사용자 기록입니다. 디자인·기능 변경 시 그대로 보존하세요.
- 동기화 구조는 이번 화면 개편에서 변경하지 않았습니다. 저장소 파일 충돌과 오프라인 미전송 데이터의 기존 제약은 남아 있습니다.
- 휴식 체크는 **이 기기의 설정과 입력한 경기 투구수**로 계산한 참고 정보입니다. 실제 리그 규정, 훈련 투구량, 몸 상태나 등판 가능 여부를 판정하지 않습니다.
- HTML 정리는 알려진 실행 경로를 제한하지만 임의의 외부 HTML을 완전히 신뢰하도록 만드는 기능은 아닙니다. 출처를 확인한 글을 사용하세요.
- 검색 제외 설정은 접근 통제가 아닙니다. 저장소와 공개 JSON의 접근 범위는 기존 설정을 따릅니다.

## 2026-10 화면·정확성 개선

핵심 기록을 먼저 보여주고 상세 통계를 접어 화면 밀도를 낮췄습니다. 모바일에서는 카드와 입력 요소를 재배치했습니다. 빈 타석의 기본 안타, 타자 경계를 넘는 연속 볼, 포지션별 경기 수, 볼넷/사구 지표 구분을 바로잡았습니다. 훈련 수정은 저장 전까지 원본을 유지하고, 명시적 백업 병합은 칼럼과 삭제 이력도 함께 다룹니다.
