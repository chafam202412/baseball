선수 정보

기기 연결 한 번만 설정하면 모든 기기에서 같은 기록을 씁니다

GitHub에 직접 저장하도록 연결합니다. 연결하면 저장할 때마다 자동으로 올라가고, 다른 기기에서 열면 최신 기록이 바로 보입니다. 파일을 내보내고 업로드하실 필요가 없습니다.

토큰 만드는 법 (한 번만)
  1. GitHub 우측 상단 프로필 → Settings
  2. 왼쪽 맨 아래 Developer settings
  3. Personal access tokens → Fine-grained tokens → Generate new token
  4. Token name: baseball · Expiration: No expiration 또는 1년
  5. Repository access → Only select repositories → baseball 선택
  6. Permissions → Repository permissions → Contents 를 Read and write 로
  7. Generate token → 나타난 문자열 복사 → 위 칸에 붙여넣기

토큰은 이 기기 브라우저에만 저장되고 사이트에는 절대 올라가지 않습니다. 기기를 분실하면 GitHub에서 그 토큰을 삭제(Revoke)하시면 됩니다.

수동 발행 기기 연결을 안 쓰실 때만 사용

이 기기의 기록을 data.json 으로 내보낸 뒤 GitHub 저장소에 올리면 방문자 화면이 그 내용으로 바뀝니다. 올리기 전까지는 아무에게도 보이지 않습니다.

올리는 법 — 저장소 baseball → Add file → Upload files → data.json 끌어다 놓기 → Commit changes. 1~2분 뒤 반영됩니다.

백업 기록은 이 브라우저 안에만 있습니다

JSON 파일은 완전한 백업입니다. 폰을 바꾸거나 브라우저를 정리해도 이 파일만 있으면 전부 되살립니다. CSV는 엑셀에서 열어보는 용도이고, 다시 불러오지는 못합니다.
