영상 · 사진 · 메모

유튜브에 영상 올리는 법 (눌러서 펼치기)
  1. 유튜브 앱 열기 → 아래 가운데 ＋ → 동영상 업로드 → 경기 영상 선택
  2. 제목 입력 (예: 260810 vs OO중 3회 타석)
  3. 공개 범위를 일부공개로 바꾸기 — 검색에 안 뜨고 링크 아는 사람만 봅니다
  4. 아동용 여부 → 아동용 아님 선택
  5. 업로드 완료 후 그 영상 열기 → 공유 → 링크 복사
  6. 아래 칸에 붙여넣기 → 경기 카드에서 바로 재생됩니다

비공개(Private)로 올리면 여기서 재생이 안 됩니다. 반드시 일부공개로.
